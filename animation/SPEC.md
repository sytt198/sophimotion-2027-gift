# Production specification

14 seconds. 1920 × 1080 pixels, 30 fps. Dark studio background, silver type, blue progress line. Silent. No ribbon, duplicated pen, tracked toy car, split S, or unrelated decorative motion.

One continuous 3D shot driven by setProgress(t/14). Caption landmarks: 0 s 2027; 4.2 s OPEN; 8.1 s EVERYDAY; 11.7 s TOGETHER. Keep the main subject inside the frame throughout and leave the final assembled open state readable.

All runtime geometry comes from the shared website scene. Frame output is independent of previous seek order. Build loads all local model assets before rendering.
